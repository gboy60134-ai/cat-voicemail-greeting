# Funniest Cat Voicemail Greeting

A one-line voicemail greeting recorded by a cat, written for the make.fun bounty [Funniest Cat Voicemail Greeting](https://make.fun/bounty/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443).

`main.ts` copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
